# 保序回归原理与校准实践

先说结论：保序回归（Isotonic Regression）是带单调约束的最小二乘，非参数、只要求拟合函数单调。它在工业界的主要用途是概率校准，把模型的预估概率拉回真实概率，同时不破坏排序。CTR/CVR 出价、uplift 决策都用它兜底。

这篇文章尽量不预设前置知识。每个概念从"它是什么、为什么存在"讲起，再落到做法和原因。

## 一、模型输出的是什么，为什么需要校准

### 1.1 分类模型的输出有两种用途

一个 CTR 模型（点击率预估模型）训练完之后，对每条曝光样本会输出一个分数。这个分数有两种用法：

1. **排序**：把分数从高到低排，决定先展示哪个商品。这种用法只关心分数大小关系，不关心分数的绝对值；
2. **出价/决策**：把分数当成"这个用户点击这条广告的概率"，拿去算钱。这种用法要求分数本身就是概率，绝对值必须准。

大部分模型天然擅长第一种，不擅长第二种。深度学习模型（DNN、树模型、各种多任务网络）输出的 sigmoid 分数，是"模型自信程度"的某种单调变换，不等于真实概率。常见偏差：整体偏高（模型对大多数样本都给出偏高的分数）、局部失真（低分段高估、高分段低估）。

### 1.2 AUC 只衡量排序，不衡量概率准不准

AUC（ROC 曲线下面积）是排序类指标：随机抽一个正样本和一个负样本，模型给正样本打更高分的概率。AUC = 0.9 的意思就是"90% 的情况下模型把正样本排在了负样本前面"。

注意这个定义里完全没出现"分数的绝对值"。一个模型把所有分数都乘 2，AUC 不变；把所有分数整体加 0.5，AUC 也不变。AUC 只对"顺序"敏感，对"刻度"无感。

广告场景里刻度错了直接是钱，举一个具体的例子（这个例子来自广告算法领域的常见讲解）[1]：

- 某广告的真实 CTR 约 0.7%，模型预估 1.0%，高估约 30%；
- 广告按点击付费（CPC 竞价），平台按 eCPM（千次展示预估收入）排序，eCPM = 预估 CTR × 单次点击出价 × 1000；
- 预估 CTR 从 0.7% 被高估到 1.0%，eCPM 从 10 涨到约 13，广告排名上升，拿到更多曝光；
- 但真实点击率还是 0.7%，广告主实际支付的点击量并没有按预估值涨，平台收入账面对上了，实际效果没跟上，广告主觉得亏，平台也流失广告主。

这里先解释几个广告基础概念（后面会一直用到）：

- **CTR**：Click-Through Rate，点击率，曝光后被点击的概率；
- **CVR**：Conversion Rate，转化率，点击后完成购买/下载等目标动作的概率；
- **eCPM**：effective Cost Per Mille，千次展示的预估收入。排序竞价时平台用它给广告排名，算得高广告就靠前；
- **OCPC/oCPX**：按转化目标优化的出价模式，平台用"预估转化率 × 广告主期望成本"来给每次点击定价。CVR 预估是它唯一的乘数，CVR 偏了出价就偏。

所以校准（Calibration）要做的事：把模型输出从"排序分"校正成"概率"，让模型说 0.8 的样本，真实约 80% 是正类 [5]。

### 1.3 监控校准质量的指标：COPC

校准做得好不好，用 COPC 看（CTR 预估的校准实践里最常用的指标）[4]：

$$\text{COPC} = \frac{\sum \text{click}}{\sum \text{pctr}}$$

分子是这段时间真实发生的点击总数，分母是模型预估的点击总数（把所有样本的预估点击率加起来）。直观理解：模型说"这段流量里应该有 100 次点击"，实际上发生了多少次？

- COPC = 1：预估和实际完全一致，校准完美；
- COPC < 1：实际点击比预估少，说明模型整体高估了点击率。广告场景里意味着出价被抬高，广告主花冤枉钱；
- COPC > 1：实际点击比预估多，说明模型整体低估，平台拿量偏保守，收入受损。

单独看一个总 COPC 不够，因为偏差通常不是均匀的。实操里把样本按预估 CTR 排序分成几十个桶，每个桶单独算 COPC，画出来就是一条"预估值 vs 实际值"的曲线：横轴是预估 CTR 的桶，纵轴是桶内 sum(click)/sum(pctr)（也就是该桶的校准表现）。典型的现象：低分段和高分段偏差大，中间段还好，这通常指向特征或样本问题，不是简单的整体缩放 [4]。

### 1.4 偏差的根因要分清：哪些该修模型，哪些才用校准

COPC 偏离 1，先查根因再动手。校准是最后一道兜底，不是第一选择 [4]：

**情况一：全量有偏**（所有流量上 COPC 都偏离 1）。根因通常是模型收敛异常或数据流问题（标签对不上、特征缺失、样本重复）。这种偏差**不建议用校准掩盖**：校准是一个静态映射，数据流的问题会随时间漂移，今天校准了明天又偏；而且掩盖问题会阻碍修根因的推进。正确做法是修数据流、修模型。

**情况二：部分流量有偏**（青年用户高估、少年用户低估，全量上看着没问题）。根因通常是两类：
1. 特征设计不合理：有区分度的特征没进模型，模型在某个子人群上系统性偏移。此时先补特征，校准治标不治本；
2. 局部训练数据不足：某个流量段样本太少，模型没学充分。

这两种情况做完特征工作和数据补强之后，残留的偏差才轮到校准上场。

**校准的基本原则**（这个原则决定了保序回归为什么是默认工具）[4]：

1. **不能改变样本的排序**。校准的目的是修概率刻度，不是重排。广告竞价依赖 eCPM 排序，排序变了等于竞价规则变了。形式上：校准前后的 AUC 应该完全不变（单调变换不改变 AUC，这个性质后面会用到）；
2. **让分桶上的 COPC 接近 1**。校准只矫正"预估 CTR 排序维度"上的有偏。特征级别的有偏（比如某个品类整体偏移）需要在特征级别解决，校准层无能为力 [4]。

## 二、保序回归：带单调约束的最小二乘

### 2.1 从普通回归到保序回归

先看一个最朴素的回归问题：给一组点 (x, y)，想找一个函数 f 让 f(x) 尽量接近 y。普通最小二乘找 $\min \sum (y_i - f(x_i))^2$，不限制 f 的形状（线性、多项式、树都可以）。

保序回归（Isotonic Regression）在这个问题里加了一个约束：

**x 越大，f(x) 必须越大（或越小）**。形式化（sklearn 用户指南的定义）[2]：

$$\min \sum_i w_i (y_i - \hat{y}_i)^2$$

约束：当 $x_i \leq x_j$ 时，$\hat{y}_i \leq \hat{y}_j$（非降）。方向也可以反过来（非增），`increasing=False` 就是反向约束 [3]。

三个设计要点，逐个说原因：

1. **为什么是平方损失**：平方损失是概率建模里最自然的选择，最小二乘有完整的统计解释（误差高斯假设下的极大似然）；它也可以换成绝对损失（L1），约束优化框架不变 [1]。选哪个看业务对异常点的敏感度：平方损失对大偏差惩罚更重，绝对损失更鲁棒；
2. **为什么有权重 $w_i$**：数据不是独立等权时，权重让每个点按重要性参与拟合。CTR/CVR 校准里最常见的情况是"按桶聚合"：每个桶代表几十万样本，桶的权重就是桶内样本量。不加权重，小桶和大桶被一视同仁，拟合会被小桶的噪声带偏 [2]；
3. **为什么是非参数**：除了单调性，不假设任何函数形式（不是线性的、不是 sigmoid 的）。这意味着它能拟合任意形状的单调失真，只要真实偏差是单调的，它就能学出来。参数化方法（比如只调一个缩放系数）只能修整体缩放，修不了"低分段高估、高分段低估"这种局部失真 [1]。

### 2.2 PAVA 算法：池相邻违反者

求解这个带约束优化问题的最经典算法是 PAVA（Pool Adjacent Violators Algorithm，池相邻违反者算法），O(n) 量级 [1]。

算法直觉先给一句：**把违反单调约束的相邻块合并成一块，用加权平均替代，重复到整个序列单调为止**。为什么合并加权平均是对的选择，后面 2.3 解释。

标准步骤 [1]：

1. 把样本按 x 从小到大排序：$x_{(1)} \leq x_{(2)} \leq \dots \leq x_{(n)}$，对应的观测是 $y_{(1)}, \dots, y_{(n)}$；
2. 从左到右扫描，检查相邻对 $y_{(k)}, y_{(k+1)}$。如果 $y_{(k)} > y_{(k+1)}$，这一对就是"违反对"：x 变大但 y 变小了，违反非降约束；
3. 把这一对合并成一个块，块的取值是两块观测值的加权平均（权重是各自的样本量 $n_k$、$n_{k+1}$）：

$$y_{(k,k+1)} = \frac{y_{(k)} \cdot n_k + y_{(k+1)} \cdot n_{k+1}}{n_k + n_{k+1}}$$

4. 合并后继续扫描：新块要跟下一个邻居再比一次，可能又违反，就继续合并；直到整个序列所有相邻块都满足非降，算法结束。

走一个完整例子（用知乎专栏的例子，数字一模一样）[1]：

假设按 x 排序后的 y 序列是 [0.05, 0.12, 0.08, 0.18, 0.22]：

- 第一对 (0.05, 0.12)：0.05 ≤ 0.12，正常；
- 第二对 (0.12, 0.08)：0.12 > 0.08，违反对！合并，加权平均（这里权重都是 1）：(0.12 + 0.08) / 2 = 0.10；
- 序列变成 [0.05, 0.10, 0.10, 0.18, 0.22]；
- 再扫一遍：0.05 ≤ 0.10，0.10 ≤ 0.10（平局算满足），0.10 ≤ 0.18，0.18 ≤ 0.22，全部满足，结束。

最终拟合值就是每个块的均值：0.05、0.10、0.10、0.18、0.22。注意 0.10 同时对应两个原始点，它们在同一个块里，共享同一个拟合值。拟合函数是**分段线性**的：块内是水平线，块与块之间线性插值 [2]。

### 2.3 为什么合并能得到全局最优

合并这个动作看起来局部，为什么它能保证全局最优？两个理由：

1. **问题本身是凸的**：平方损失是凸函数，单调约束是线性不等式约束，整个问题是凸二次规划。凸问题的任何局部最优解就是全局最优解 [2]（这块是 Barlow 1972 专著的标准结论，本次调研没抓到一手原文，引用前建议核实）；
2. **合并的语义**：把两个违反约束的点合并成加权平均，等价于"放弃这两个点各自独立的拟合值，让它们共享一个值"。这个共享值在最小二乘意义下就是块内均值。PAVA 的每一步合并都对应一条被激活的约束，扫描一轮后所有约束都满足，就停在最优解上。

用 2.2 的例子验证：合并后总平方损失是多少？原序列 y 是 [0.05, 0.12, 0.08, 0.18, 0.22]（假设这就是观测值本身），拟合值是 [0.05, 0.10, 0.10, 0.18, 0.22]，损失 = 0 + (0.12-0.10)² + (0.08-0.10)² + 0 + 0 = 0.0004 + 0.0004 = 0.0008。任何不违反约束的其他拟合方案，损失都不会比这个小，因为违反约束的唯一处理方式就是让这两个点靠近，而它们的加权平均是最近的选择。

### 2.4 一个容易混淆的点：保序回归 vs 单调变换

有人会把保序回归理解成"把模型输出映射到真实概率的任意单调函数"，这个理解方向对，但有个边界：保序回归是**数据驱动的**，它不假设变换形式，完全由 (x, y) 数据决定形状；而"任意单调函数"如果参数化（比如 logit 线性变换），就是另一类方法（sigmoid 校准，见第五章）。保序回归的非参数性既是优点（拟合能力强）也是风险（容易过拟合，尤其样本少时，sklearn 明确提示这一点）[5]。

## 三、sklearn 参数

sklearn 的 `IsotonicRegression`，落地时每个参数都要理解，其中有一个是上线必踩的坑 [3]：

1. **`increasing`：True / False / auto**。True 是非降约束，False 是非增约束。`auto` 会根据 Spearman 秩相关系数的符号自动判断方向。Spearman 秩相关不要求线性关系，只衡量"x 增大时 y 是否倾向于增大"，正好匹配保序回归"只要求单调"的语义。不确定方向时用 auto，让数据说话；
2. **`y_min` / `y_max`：预测值的上下界**。校准概率时设 [0, 1] 很自然。注意它只钳制极值，不改变中间形状；
3. **`out_of_bounds`：训练域外的 x 怎么处理，默认 nan**。这是最容易踩的坑：训练时见过的 x 范围是 [min, max]，线上来了一个更大的 x（新特征区间，比如新用户群的预估分数超出训练分布），默认行为是直接返回 NaN。NaN 会顺着管道传播：排序时 NaN 排到最后，出价时 NaN 直接报错或算成 0。**上线必须显式设 `clip`**，把域外的 x 钳到端点值，保证永远有输出；
4. **ties（平局）处理**：x 有大量重复值（分位数分桶后必然出现）时，同一个 x 对应多个 y，块合并的顺序会影响结果。sklearn 用 de Leeuw 1977 的 secondary method 处理 [3]。工程上注意：分桶太细时平局很多，曲线形状可能不稳定，验证时多看两眼。

Spark 生态：mllib 自带 `IsotonicRegressionV2`，用法是准备 (x, y) 对排序后训练，线上做查表 [4]。

## 四、概率校准：sigmoid 还是 isotonic

校准器选型是落地时的第一个决策。sklearn 提供两种，背后的假设完全不同 [5]。

### 4.1 sigmoid 校准（Platt scaling）

Platt 1999 年提出（Platt 1999 是为 SVM 设计的，原文见 sklearn 文档引用）。做法：把模型原始输出 f 过一个带两个参数的 sigmoid：

$$p(y=1|f) = \frac{1}{1 + \exp(Af + B)}$$

A、B 用极大似然估计拟合。

它背后的假设：**校准曲线本身是 sigmoid 形状的**，也就是说原始输出的偏差可以用一个 sigmoid 完全纠正。这个假设在什么情况下成立？Platt 原文的验证：SVM + 常见核函数时经验上成立。为什么不普遍成立：sigmoid 只包含两个自由度（缩放 A 和偏移 B），它只能修"整体缩放 + 整体偏移"这类简单的单调失真；如果真实偏差是"低分段高估、中段正常、高分段低估"这种 S 形之外的形状，sigmoid 修不了 [5]。

还有一个更严格的统计条件：sigmoid 校准的最优性要求两类样本的输出都服从正态分布且方差相同（对称误差假设）。类别不平衡时这个条件几乎必被违反，负样本远多于正样本时，两类输出的方差差异很大 [5]。

### 4.2 isotonic 校准

保序回归校准：拟合一个非参数单调函数，把原始输出映射到校准概率。唯一假设是"映射单调递增"（原始输出高，校准后概率也高）。

对比总结（sklearn 的明确结论）[5]：

| 维度 | sigmoid | isotonic |
|------|---------|----------|
| 假设 | 校准曲线是 sigmoid 形状；两类输出同方差 | 只要求映射单调 |
| 表达力 | 两个参数，只能修简单单调失真 | 任意单调失真都能修 |
| 过拟合风险 | 低（两个参数） | 高（非参数），小样本时明显 |
| 数据足够时的表现 | 可能不如 isotonic | **>= sigmoid** |

结论：CTR/CVR 这类大样本场景（日级样本量百万到亿级），直接上 isotonic，不用纠结。小样本场景（几千样本）考虑 sigmoid 的方差优势 [5]。

### 4.3 校准质量怎么评估

校准曲线（reliability diagram，可靠性图）：把测试样本按预测概率分桶，每个桶算两个值：桶内平均预测概率（x 轴）和桶内真实正样本率（y 轴）。画出来越贴对角线（y = x），校准越好。偏离对角线的形态有诊断意义：整体在对角线上方 = 低估，下方 = 高估，S 形 = 中段失真 [5]。

注意别用 Brier score 单独判断校准好坏：Brier score 可以分解成校准误差 + 区分度 + 数据噪声三项（Murphy 分解）[5]。**Brier 更低不代表校准更好**，可能只是区分度（分辨率）更高。判断校准要用校准曲线或分解后的校准项，不要用混合指标。

## 五、CTR/CVR 校准的工业落地全流程

把前面所有概念串起来，走一遍完整的落地流程（这是广告/推荐 CTR 校准的标准做法）[1,4]：

**第一步：准备训练数据。**

从线上日志拿样本：每条曝光记录有特征 x 和真实标签 y（点击/未点击）。按模型预估的 pctr 排序，分成桶（实操常用 100~1000 桶）[4]。

为什么要分桶而不是直接用原始样本：原始样本的 pctr 是连续值，同一个 pctr 值上的样本太少，直接按样本级拟合噪声太大。分桶后每个桶有几十万样本，桶内统计量稳定。桶数怎么定：太细（上万桶）噪声大、太粗（十几个桶）精度损失。100~1000 是实践经验的合理区间 [4]。

**第二步：桶内统计真实 CTR。**

每个桶算 sum(click) / sum(impression)，也就是桶内真实点击率，作为该桶的 y 值；桶的 x 值用桶内平均 pctr。权重 = 桶内样本量 [4]。

**第三步：喂保序回归。**

把 (桶平均 pctr, 桶真实 ctr) 序列喂给保序回归，带权重。这一步解决"低分段高估、高分段低估"这类单调失真：保序回归会压高低分段的拟合值、抬高高分段的拟合值，同时保证单调。

**第四步：检查拟合曲线。**

三个检查点：曲线单调（应该天然满足）；分段线性（块别太多，块太多说明桶太细）；两端别太陡（两端陡通常说明极端桶样本量不足，考虑合并桶）。

**第五步：上线。**

线上预测时查表 + 线性插值：找到输入 pctr 落在哪个块区间，取该区间的拟合值（块内是水平线，块间线性插值）。域外值用 clip 兜底（第三章的坑）[4]。Spark 的 IsotonicRegressionV2 训练完导出的是分块表，线上直接查 [4]。

**两个边界，落地前想清楚 [4]：**

1. 校准只矫正"pctr 排序维度"上的有偏。如果偏差和某个特征维度（品类、人群）强相关，校准层看不到这个维度，修不了，那要在特征级解决；
2. 校准前后 AUC 必须不变。这是校验手段：跑完校准如果 AUC 变了，说明实现有问题（要么破坏了单调性，要么数据泄漏）。

## 六、uplift 建模里的保序回归：IPW 代理标签

保序回归在因果推断场景（uplift 建模）里还有一个重要应用：校准 uplift 模型的输出。这个场景值得单独讲，因为它的标签构造方式很不一样。

### 6.1 什么是 uplift，为什么真实 uplift 不可观测

uplift（增量建模）：估计"给用户发券 vs 不发券"对用户行为的增量效果。比如：发了 5 元券，这个用户的购买概率提高了多少？建模目标 $\tau = Y(1) - Y(0)$，Y(1) 是处理组（发券）的 outcome，Y(0) 是对照组（不发券）的 outcome。

关键难点：**对任何一个用户，只能观察到一边**。发了券就看不到"如果不发券他会怎样"，不发券就看不到"如果发了券他会怎样"。$\tau$ 对每个个体都是反事实，永远观测不到 [1]。

那模型怎么训练？需要一个"代理标签"：每个样本能算出一个值，它的期望等于真实 uplift。这就是 IPW（Inverse Propensity Weighting，逆倾向加权）。

### 6.2 IPW 怎么构造代理标签

先定义倾向得分 e(x) = P(T=1 | X=x)，样本被分到处理组的概率。随机实验（流量随机分桶）下，e 就是处理组占比，一个常数。

每个样本的 IPW 贡献值：

$$\text{IPW}_i = \left( \frac{T_i}{e} - \frac{1-T_i}{1-e} \right) \cdot Y_i$$

T_i 是处理指示（1=处理组，0=对照组），Y_i 是观测 outcome。

这个公式为什么有效，走一遍期望推导 [1]：处理组的样本，IPW 值 = Y_i / e；对照组的样本，IPW 值 = -Y_i / (1-e)。对全体样本求期望：

$$\mathbb{E}[\text{IPW}] = \mathbb{E}\left[ \frac{T \cdot Y}{e} \right] - \mathbb{E}\left[ \frac{(1-T) \cdot Y}{1-e} \right] = \mathbb{E}[Y(1)] - \mathbb{E}[Y(0)] = \text{ATE}$$

中间一步用到了"处理分配与 outcome 独立（随机实验）"：处理组的 Y 均值就是 E[Y(1)]，对照组的就是 E[Y(0)]。所以每个样本的 IPW 值虽然在个体层面噪声很大（它要么是 Y/e 要么是 -Y/(1-e)，都是放大的量），但期望是对的。

### 6.3 为什么保序回归适合给 IPW 标签做校准

IPW 标签的个体噪声非常大（方差大），直接拿它当回归目标拟合会过拟合噪声。但它的排序信息基本可靠：真实 uplift 高的样本，IPW 值期望上也高。

保序回归恰好匹配这个性质：单调约束强迫拟合曲线"只保留排序信息"：A 的原始 uplift 预测高于 B，校准后仍然高于 B。这对发券/不发券的阈值决策是硬需求：决策逻辑是"预估 uplift 超过阈值就发券"，如果校准破坏了排序，阈值决策就乱了 [1]。

所以完整链路是：模型输出原始 uplift 预测 → 用 IPW 代理标签做训练目标 → 保序回归拟合校准函数 → 用校准后的 uplift 做阈值决策 [1]。

## 七、我的判断和落地清单

1. **校准是保序回归的主场**。任何"排序对但绝对值偏"的场景（eCPM 出价、oCPX 定价、CVR 校准）直接上，收益确定、改动小（只加一层查表）；
2. **它救不了排序错误**。保序回归只修单调失真。如果模型本身排序就不对（特征缺失、样本偏差），校准层无能为力，先修模型，再谈校准；
3. **大样本是前提**。非参数方法全靠数据说话，样本不够就过拟合（sklearn 明说）[5]。小样本降桶数或用 sigmoid；
4. **别拿校准掩盖数据流问题**。COPC 偏离先查根因：全量偏查数据流和收敛，局部偏查特征，最后才轮到校准 [4]；
5. **上线前检查三件套**：`out_of_bounds` 设 `clip` 了没；拟合曲线两端陡不陡；校准后 AUC 有没有变。
