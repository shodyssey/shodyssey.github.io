LTV 建模的分布假设与技术分析

调查主题：LTV（Customer Lifetime Value，客户生命周期价值）

一、LTV 建模是什么

LTV 是客户在未来固定周期（1/2/3 年，工业界也常用 7 天等短周期）内的总消费价值。它的业务价值直接而暴力：广告出价、预算分配、客户分层营销——预测越准，每一分获客成本花得越值 [1,2]。

但 LTV 标签的分布形态是建模者的噩梦，两篇论文都从同一个观察出发：

  • 大量精确的零——一次性购买者再不回购（零膨胀）；
  • 正值部分重尾右偏——少数"鲸鱼"用户贡献大部分收入，跨越多个数量级（80/20 法则）。

MSE 在这里双重失败：高斯假设装不下零尖峰，平方惩罚又被鲸鱼的极端值拉爆——训练不稳定、向多数标签（低值）系统性偏置 [1]。这正是本站《损失函数背后的分布假设》一文反复论证的结论：没有任何单一分布能同时装下零点质量和正值重尾。

更细致地看，MSE 的失败是双向的张力 [5]：零值太多时，模型只需把所有预测压向零就能取得很小的 loss（向零坍缩）；而极大值的存在又让训练 loss 剧烈浮动，甚至为真实为零的用户预测出偏大的值（被极端值拉爆）——两个失败模式方向相反，单一平方损失无法同时避免。

ZILN 处在谱系的枢纽位置：它继承了统计模型时代的分布思想（对数正态金额假设在 Hierarchical Bayes 时代就已出现），又用深度学习的表达能力把它落地——此后快手 MDME、腾讯 ExpLTV、华为 CMLTV 全部以它为起点或 building block。

二、Google ZILN

《A Deep Probabilistic Model for Customer Lifetime Value Prediction》（Xiaojing Wang, Tianqi Liu, Jingang Miao，Google，arXiv:1912.07753，2019）[1]

2.1 核心思想

把 LTV 的条件分布建模为零点质量 + 对数正态的混合——零膨胀对数正态（ZILN）分布（完整的假设声明与似然推导见附录 A）。损失函数由负对数似然推导，天然分解为两个任务（论文 Eq. 4）：

LZILN(x;p,μ,σ)=LCrossEntropy(1{x>0}; p)⏟分类：是否回购+1{x>0} LLognormal(x;μ,σ)L^{ZILN}(x; p, \mu, \sigma) = \underbrace{L^{CrossEntropy}\big(\mathbb{1}_{\{x>0\}};\, p\big)}_{\text{分类：是否回购}} + \mathbb{1}_{\{x>0\}}\, L^{Lognormal}(x; \mu, \sigma) LZILN(x;p,μ,σ)=分类：是否回购LCrossEntropy(1{x>0}​;p)​​+1{x>0}​LLognormal(x;μ,σ)

其中对数正态损失（论文 Eq. 1）：

LLognormal(x;μ,σ)=log⁡(xσ2π)+(log⁡x−μ)22σ2L^{Lognormal}(x; \mu, \sigma) = \log(x\sigma\sqrt{2\pi}) + \frac{(\log x - \mu)^2}{2\sigma^2} LLognormal(x;μ,σ)=log(xσ2π​)+2σ2(logx−μ)2​

一个损失同时学「是否回购」与「回购金额」，替代了传统的两阶段方案（先分类器预测回购、再回归器预测金额），工程复杂度直接减半。完整推导见本站《损失函数背后的分布假设》附录 G。

2.2 三头结构与异方差

DNN 最后一层输出三个 pre-activation logits，分别决定：

头 参数 激活函数 含义
ppp 回购概率 sigmoid 零膨胀质量
μ\muμ 对数均值 identity 对数正态位置
σ\sigmaσ 对数尺度 softplus 对数正态尺度

中间层共享表示，本质是多任务学习：分类任务与回归任务互相正则化。论文特别强调一个细节：σ\sigmaσ 不是 nuisance 参数——它也作为输入特征的函数被学习（异方差 heteroscedastic 建模），且其估计质量直接影响均值预测的无偏性，因为

E(X)=exp⁡(μ+σ22)E(X) = \exp\left(\mu + \frac{\sigma^2}{2}\right) E(X)=exp(μ+2σ2​)

σ\sigmaσ 被低估会系统性拉低均值预测。此外对数正态损失可视为对数变换后的加权 MSE（σ\sigmaσ 扮演权重角色），相比 MSE 的对称惩罚，它对高值惩罚更轻、argmin 随 σ\sigmaσ 增大而移动（论文 Figure 2）。

2.3 不确定性量化红利

因为输出的是完整预测分布，除点预测外还能免费获得分位数区间（对数正态的分位数有闭式解）——这是概率式建模相对纯回归的额外红利，可用于风险敏感的预算决策。

2.4 评估方法论

LTV 评估不能只看 MSE/MAE（训练目标已不是它们）。论文给出组合拳：

  • Normalized Gini 系数（判别力）：按预测 LTV 降序排客户画累计收益曲线，与按真实 LTV 排序的 Lorenz 曲线（80/20 曲线）对比；normalized = model Gini / label Gini，落在 0 到 1 之间。纯基于排序、对校准误差不敏感——广告出价场景只需要序。它与 AUC 的关系：Gini = 2 × AUC − 1；
  • Decile charts + MAPE（校准力）：按预测十分位分桶，对比桶内预测均值与真实均值，MAPE = Σ|ŷ_i − y_i| / y_i；
  • Spearman 秩相关：比 Pearson 更抗离群值。

2.5 实验结果

两个公开数据集：Kaggle Acquire Valued Shoppers（311K 客户、33K 公司，预测首购后 12 个月总购买额）与 KDD Cup 98。DNN 为两个隐层（64/32 units）、Adam、early stopping。

  • Spearman 相关：ZILN vs MSE，线性模型平均 +23.9%，DNN 平均 +48.0%；
  • Normalized Gini：DNN-ZILN 相比 baseline（按首购金额排序）平均提升 23.1%；线性 + MSE 在部分公司甚至输给 baseline——MSE 在离群值下连收敛都成问题；
  • ZILN 框架下 DNN 比线性模型平均再提升 2.2%。

排序正则（order loss）。工程实践中可以在 ZILN 损失上叠加时间一致性约束，例如：

Lorder=mean(ReLU(LTV^30−LTV^90))L_{order} = \text{mean}\big(\text{ReLU}(\hat{LTV}_{30} - \hat{LTV}_{90})\big) Lorder​=mean(ReLU(LTV^30​−LTV^90​))

D(X)=(eσ2−1) e2μ+σ2D(X) = (e^{\sigma^2} - 1)\, e^{2\mu + \sigma^2} D(X)=(eσ2−1)e2μ+σ2

方差随 σ\sigmaσ 指数增长——这正是重尾的数学表达，也是 σ\sigmaσ 头必须认真学习的另一个理由。

三、腾讯 ExpLTV

《Out of the Box Thinking: Improving Customer Lifetime Value Modelling via Expert Routing and Game Whale Detection》（Shijie Zhang, Xin Yan, Xuejiao Yang, Binfeng Jia, Shuangyang Wang，腾讯，CIKM 2023）[2]

3.1 动机：鲸鱼是分布中的分布

场景是手游 UA（用户获取）广告投放：按预估 LTV 为每个广告位出价。鲸鱼用户（game whales，重氪玩家，中文社区俗称"大R"）在三个游戏数据集中只占 0.459% ~ 1.21%，却贡献游戏总收入的 50% ~ 80% [2,4]，且其购买行为分布与普通用户质的不同。

单一 ZILN 的 (μ,σ)(\mu, \sigma)(μ,σ) 要同时伺候两类人群，谁都伺候不好。论文的关键洞察是：鲸鱼检测与 LTV 预测是互益的两个任务，此前没有工作将它们统一建模。

3.2 鲸鱼检测器——软标签回归 + 贝叶斯分解

不用硬阈值 gu∈{0,1}g_u \in \{0,1\}gu​∈{0,1} 做二分类（丢失货币价值的内在排序），而是设计软标签（论文 Eq. 1）：

pugwptr=p(gu=1,su=1∣xu)=1−e−LTVu/Rp_u^{gwptr} = p(g_u{=}1, s_u{=}1 \mid x_u) = 1 - e^{-LTV_u / R} pugwptr​=p(gu​=1,su​=1∣xu​)=1−e−LTVu​/R

其中 su=1s_u = 1su​=1 表示购买行为已发生，RRR 为鲸鱼阈值。检测任务因此从二分类变成回归——既保留"谁更值钱"的排序信息，又能按概率分桶做定制化营销。这一映射的边界行为（p(0)=0p(0)=0p(0)=0 与"鲸鱼必先购买"自洽、阈值处约 63.2%、饱和于 1）、单调性与形式来源见附录 B.1。

再拆成行为链 convert → purchase → game whale，用贝叶斯分解（论文 Eq. 8）：

p^ugwptr=p^uptr⏟购买率×p^ugw⏟条件鲸鱼概率\hat{p}_u^{gwptr} = \underbrace{\hat{p}_u^{ptr}}_{\text{购买率}} \times \underbrace{\hat{p}_u^{gw}}_{\text{条件鲸鱼概率}} p^​ugwptr​=购买率p^​uptr​​​×条件鲸鱼概率p^​ugw​​​

这一拆同时解决两个经典问题：

  • 数据稀疏（DS）：鲸鱼仅约 0.7%，但购买行为占约 11%——把购买率作为辅助任务，为检测器引入丰富得多的监督信号；
  • 样本选择偏差（SSB）：在全样本空间上建模 p^gwptr\hat{p}^{gwptr}p^​gwptr（购买与鲸鱼的联合概率），而不是只在已购买子集上建模条件概率 p^gw\hat{p}^{gw}p^​gw，避免训练与 serving 的分布不一致。

中文社区解读 [4] 点破了这一设计与阿里 ESMM 的思想同源：ESMM 用"曝光→点击→转化"的全空间建模解决 CVR 的样本选择偏差，ExpLTV 用"曝光→购买→鲸鱼"的同一套贝叶斯分解解决大R 检测的 SSB。我的判断是，"概率链式分解 + 全空间监督"正在成为这类稀疏后链路问题的标配解法——两个场景相隔六年、不同公司，答案的骨架却一模一样，这不太可能是巧合。

检测器最后一层是 softmax，输出二维概率向量 (p^gw,p^ngw)(\hat{p}^{gw}, \hat{p}^{ngw})(p^​gw,p^​ngw)——条件鲸鱼概率与条件低消费者概率，训练损失为交叉熵 + KL 散度约束（论文 Eq. 10）。

3.3 专家路由——检测器当门控

两个 LTV 专家——鲸鱼专家与低消费者专家——每个专家内部都是完整的 ZILN 结构（ppp、μ\muμ、σ\sigmaσ 三头，激活函数同论文一）。检测器输出的概率作为软路由权重（论文 Eq. 12）：

3.5 实验结果

三个腾讯手游工业数据集（GAME A/B/C：29.3 万 / 13.5 万 / 22.1 万用户，鲸鱼占比 0.459% / 0.675% / 1.21%，购买率 11.8% / 7.5% / 14.4%），以 T=7 天累积消费为 LTV 标签（时效性优先于完整性）。

  • LTV 预测（normalized Gini）：相比最强 baseline 分别提升 1.5% / 3.8% / 6.2%；ZILN 系方法普遍优于 MSE 系方法，再次验证分布假设的正确性；
  • 鲸鱼检测（Recall@K）：全面领先，搜索预算越紧优势越大——GAME A 的 R@500 相对提升 11.4%；K=5000 时三个游戏都能召回 70%+ 的鲸鱼；
  • 最有说服力的细分证据：只看高消费者子集的 Gini，相比最强 baseline 提升 0.303 / 0.082 / 0.122，远大于全体消费者的提升（0.074 / 0.04 / 0.054）——证明专家路由确实把鲸鱼"伺候"好了；
  • 消融实验：去掉专家结构（-ne）、去掉 SSB 处理（-nssb）、去掉参数共享（-sp），各项指标全部下降；
  • 一个反直觉发现：纯 LTV 模型（如 WDL、DeepFM）在 Gini 上赢过 DCN，鲸鱼检测的 R@K 却更低——没有鲸鱼意识的模型只会伺候多数标签，无法稳定把鲸鱼排在最前。

四、技术脉络——分布假设的演进

三个与本站已有内容的呼应：

  1. 《损失函数背后的分布假设》3.7 节与附录 G 的 ZILN 推导与论文一完全对应（损失分解、三头激活、期望公式）——论文一补充了我们未覆盖的细节：异方差 σ(x)\sigma(x)σ(x) 对均值无偏性的影响、不确定性量化红利、以及完整的评估方法论；
  2. 《Weighted Logistic Regression 调查报告》4.4 节的"单标量表达力不足"问题，在 ExpLTV 中被系统性解决：多头（ppp、μ\muμ、σ\sigmaσ 分离）+ 多专家（人群分离），把"是否花钱"“花多少”"哪类人"三个自由度全部解耦；
  3. "选损失 = 选分布假设"的地图继续扩张：当单一分布装不下异质人群时，答案沿着"混合分布"走——每个专家一个 ZILN，MoE 思想在概率建模里的自然延伸。

4.1 ZILN 是一条被反复引用的主干

调查中文社区对这两篇论文的解读后，ZILN 的"基础设施"属性比我一开始想的更明显：

  • ExpLTV 明确以 ZILN 为 building block：腾讯云的论文解读开篇即指出"μ 和 σ 是谷歌 19 年提出的 ZILN 方法……本文是在 ZILN 的基础上进行改进的，阅读本文需要一些 ZILN 的知识" [4]——两个 LTV 专家内部就是完整的 ZILN 三头结构，ExpLTV 的全部创新都发生在"如何混合多个 ZILN"这一层；
  • 快手 MDME（CIKM 2022）：十亿用户规模的工业方案，同样从"单一分布装不下复杂不平衡的 LTV 分布"出发，走向多分布专家混合——与 ExpLTV 的专家路由殊途同归，而分布假设的起点仍是 ZILN 确立的"零膨胀 + 重尾正值"框架 [3]；
  • 华为 CMLTV（2024）：对比学习多视角网络，作为即插即用模块兼容大部分基准网络——"基准网络"里就包括 ZILN 系方法 [4]；
  • 本站的 ZILN 推导：损失函数博客附录 G 的完整推导与论文一逐式对应，说明这套数学已经足够标准化，成为后续工作默认的"公共组件"。

一个值得记录的实践者视角 [4]：LTV 是强场景属性的问题——翻遍文献没有统一 benchmark，各方法都是针对自身场景的分布特性提出的，跨场景只能参考思路不能照搬模型。ZILN 之所以能成为主干，靠的是它提供了一个可组合的分布假设原语，而不是某个具体模型：零膨胀对数正态这一层是稳定的，人群异质性、时间一致性、多视角集成等场景差异都在它之上叠加。

正样本极少（<1%） 拆行为链做辅助任务，全空间建模抗 SSB 论文二
预测周期选择 短周期（7 天）优先，时效性 > 完整性 论文二
检测任务设计 软标签回归保留排序，避免硬阈值二分类 论文二

六、小结

LTV 建模的全部演进史就是一部「让分布假设追上数据形态」的历史：MSE 假设错了分布（高斯），ZILN 找对了分布（零膨胀对数正态），ExpLTV 发现一组参数装不下所有人群（混合专家）。每一次进步都不是更大的模型，而是更诚实的假设。这条演进史对我选方法的启发很直接：预测效果不行时，先怀疑分布假设，再怀疑模型能力——这个顺序反了，调再大的模型也是白调。

目标：在全样本空间上估计 pugwptr=p(gu=1,su=1∣xu)p_u^{gwptr} = p(g_u{=}1, s_u{=}1 \mid x_u)pugwptr​=p(gu​=1,su​=1∣xu​)（购买且是鲸鱼的联合概率）。

B.3 参数插值与分布混合的辨析

  • 分布混合（另一种可能）：LogNormal(μ1,σ1)\text{LogNormal}(\mu_1,\sigma_1)LogNormal(μ1​,σ1​) 与 LogNormal(μ2,σ2)\text{LogNormal}(\mu_2,\sigma_2)LogNormal(μ2​,σ2​) 按权重叠加，得到的是双峰混合分布——表达能力更强（能同时保留两个人群的形态），但期望没有简单闭式，且与 ZILN 损失的兼容需要重新推导。
