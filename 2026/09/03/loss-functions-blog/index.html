损失函数背后的分布假设

上一篇讲逻辑回归时我们反复用到一个事实：交叉熵损失不是工程选择，而是伯努利分布下极大似然估计的解析形式。这个事实可以推广：几乎每一个常见损失函数，都是"对标签分布做某种假设 + 极大似然估计"这对组合的必然产物。选损失函数，本质是在选分布假设。

这篇文章把这个统一视角展开：先建立"假设分布 → 写似然 → 取负对数 → 得到损失"的四步模板，然后用它逐一推导回归家族（MSE、MAE、Huber、Log-Cosh、Quantile、泊松）和分类家族（0-1、交叉熵、Hinge、指数、Focal Loss），最后给出工程选型建议。正文只保留推导主线与结论，完整推导统一放在附录，且附录的每一步都标注依据，不跳步。

一、概念地基

三个经常混用的词先区分清楚 [4]：

  • 损失函数（Loss Function）：定义在单个样本上，衡量一个样本的预测误差，记 L(y,f(x))L(y, f(x))L(y,f(x))；
  • 代价函数（Cost Function）：定义在整个训练集上，是所有样本损失的平均，如 1N∑iL(yi,f(xi))\frac{1}{N}\sum_i L(y_i, f(x_i))N1​∑i​L(yi​,f(xi​))；
  • 目标函数（Object Function）：最终优化的函数，等于代价函数加上正则项（经验风险 + 结构风险）。

下文谈"某某损失"时指单样本损失，推导时对全体样本求和即得代价函数。

二、统一模板

设模型预测分布为 p(y∣x;θ)p(y \mid x; \theta)p(y∣x;θ)，训练样本 (xi,yi)(x_i, y_i)(xi​,yi​) 独立同分布。四步模板：

第 1 步（假设）：对标签的生成机制做一个分布假设，写出 p(y∣x;θ)p(y \mid x; \theta)p(y∣x;θ)。四步里我最看重这一步：假设什么分布，就得到什么损失，后面三步都只是机械操作。

第 2 步（连乘）：i.i.d. 假设下，全体样本的似然是各样本概率的连乘：

∏i=1Np(yi∣xi;θ)\prod_{i=1}^{N} p(y_i \mid x_i; \theta) i=1∏N​p(yi​∣xi​;θ)

第 3 步（取对数）：连乘不便优化，取对数把连乘化为求和（对数单调，不改变极值点位置）：

∑i=1Nlog⁡p(yi∣xi;θ)\sum_{i=1}^{N} \log p(y_i \mid x_i; \theta) i=1∑N​logp(yi​∣xi​;θ)

第 4 步（取负丢常数）：最大化对数似然等价于最小化其相反数；与参数 θ\thetaθ 无关的项可以丢弃。剩下的就是损失函数：

L(θ)=−∑i=1Nlog⁡p(yi∣xi;θ)+const\mathcal{L}(\theta) = -\sum_{i=1}^{N} \log p(y_i \mid x_i; \theta) + \text{const} L(θ)=−i=1∑N​logp(yi​∣xi​;θ)+const

这个模板的用处很直接：每一个常见损失函数，都能在某个具体的分布假设下从它推导出来。下面逐个验证。

三、回归损失家族

3.1 MSE 与高斯分布

假设观测值与预测值的差异来自高斯噪声：y=f(x;θ)+εy = f(x;\theta) + \varepsilony=f(x;θ)+ε，ε∼N(0,σ2)\varepsilon \sim N(0, \sigma^2)ε∼N(0,σ2)。代入模板（完整推导见附录 B），对数似然中与 θ\thetaθ 相关的项只剩：

最大化它等价于最小化 ∑i(yi−f(xi;θ))2\sum_i (y_i - f(x_i;\theta))^2∑i​(yi​−f(xi​;θ))2——均方误差（MSE）。所以"回归用 MSE"翻译过来就是"我假设噪声是高斯的"。高斯噪声假设何时合理？大量微小独立噪声源叠加时，中心极限定理保证噪声近似高斯——这是它成为默认选择的原因。

MSE 的两个特点都源于平方结构：对离群点敏感（误差被平方放大），梯度 ∝\propto∝ 误差本身（预测越准梯度越小，收敛末期精细）。

3.2 MAE 与拉普拉斯分布

假设噪声服从拉普拉斯分布（密度见附录 A.1，形状是尖峰重尾）：ε∼Laplace(0,b)\varepsilon \sim \text{Laplace}(0, b)ε∼Laplace(0,b)。代入模板（完整推导见附录 C），负对数似然中与参数相关的项为：

最小化它就是平均绝对误差（MAE）。拉普拉斯分布重尾，对应"噪声中偶发大幅偏离"的场景——这正是 MAE 对离群点鲁棒的分布根源：重尾假设天然包容异常值，而不是像高斯那样把异常值视为"极小概率事件"而拼命拉扯。

3.3 收敛目标——均值 vs 中位数

MSE 和 MAE 最实质的差异体现在收敛目标上 [5]。固定一个输入 xxx，模型对它的预测记为 ttt，训练数据中该输入对应一组标签 {yi}\{y_i\}{yi​}，两种损失的最优解：

  • MSE 下对 ttt 求导：∂∂t∑i(t−yi)2=0\frac{\partial}{\partial t}\sum_i (t - y_i)^2 = 0∂t∂​∑i​(t−yi​)2=0 解得 t=1N∑iyit = \frac{1}{N}\sum_i y_it=N1​∑i​yi​——均值；
  • MAE 下求导：∂∂t∑i∣t−yi∣=∑isgn(t−yi)=0\frac{\partial}{\partial t}\sum_i |t - y_i| = \sum_i \text{sgn}(t - y_i) = 0∂t∂​∑i​∣t−yi​∣=∑i​sgn(t−yi​)=0，解得 ttt 使两侧样本数相等——中位数（推导见附录 C.3）。

一个直观例子 [5]：某样本的标签出现三次，分别是 2、4、9（9 是异常值）。MSE 训练的模型收敛到均值 5，被异常值拉偏；MAE 收敛到中位数 4，纹丝不动。"MSE 对异常值敏感"不是平方的算术巧合，而是"高斯假设下均值就是最优位置参数"的统计必然。拉普拉斯分布位置参数的 MLE 恰好是中位数，两个视角在这里对上了。

代价是：MAE 的梯度恒为 ±1\pm 1±1，预测已经很准时梯度却不衰减，收敛末期容易在最优点附近震荡（学习率不衰减的话）。

3.6 泊松损失与计数数据

当目标是计数（点击次数、到店人数、单位时间请求数）时，高斯假设失效（计数非负、方差随均值增长）。正确的假设是泊松分布：y∼Poisson(λ)y \sim \text{Poisson}(\lambda)y∼Poisson(λ)，配对数链接 λ=eη\lambda = e^{\eta}λ=eη 保证 λ>0\lambda > 0λ>0。代入模板（推导见附录 D），损失为：

这就是泊松回归损失。它的分布假设精确刻画了"计数"的数据机制：泊松分布的均值等于方差，天然匹配"越大的目标越喧闹"的计数现象。

3.7 零膨胀对数正态损失——时长与价值建模

预测用户观看时长或广告转化价值时，数据呈现出一种复合形态：大量精确的零（没点击就没有时长）加上正值部分的重尾右偏（少数用户贡献超长时长）。逐一检验手上的分布假设会发现全军覆没：高斯允许负值且薄尾；泊松是离散分布，方差等于均值的约束太强；对数正态能装重尾，但 log⁡0\log 0log0 无定义——没有任何一个单一分布能同时装下"零点质量"和"正值重尾"。

四、分类损失家族

4.1 0-1 损失与代理损失

分类最理想的损失是 0-1 损失：分对零损失，分错单位损失。但它不可导且非凸，无法用梯度优化；而且它只看对错、不看置信度，无法惩罚"差一点分错"的边界样本。工程上必须用它的凸代理：一个可导的、对 0-1 损失的上界近似。下面三个损失都是 0-1 的代理，区别在代理的方式。

4.2 交叉熵——伯努利/多项分布的必然

上一篇已完整推导：标签服从伯努利分布，极大似然 = 最小化交叉熵。多分类时标签服从多项分布，配 softmax 链接，同样推出交叉熵 [1,2]。这里补充第三个视角——KL 散度 [2]（推导见附录 E）：

DKL(P ∥ Q)=H(P,Q)−H(P)D_{KL}(P \,\|\, Q) = H(P, Q) - H(P) DKL​(P∥Q)=H(P,Q)−H(P)

其中 PPP 是真实标签分布，QQQ 是模型预测分布，H(P)H(P)H(P) 是真实分布的熵、与模型参数无关。因此最小化交叉熵 = 最小化 KL 散度 = 最大化似然——三个目标在分类问题里是同一件事。交叉熵惩罚"过度自信的分错"极其严厉（−log⁡p→∞-\log p \to \infty−logp→∞），这是它优于 0-1 损失的代理质量来源。

4.3 Hinge 与指数损失

Hinge（合页）损失 [4]：L=max⁡(0,1−yz)L = \max(0, 1 - yz)L=max(0,1−yz)（y∈{−1,+1}y \in \{-1,+1\}y∈{−1,+1}，zzz 为打分）。分对且间隔足够（yz≥1yz \ge 1yz≥1）时损失为零——它只关心边界附近的样本，这正是 SVM 最大间隔的损失根源。相比交叉熵的全局软惩罚，hinge 对"分得足够对"的样本零梯度，更鲁棒于远端样本，但不输出概率。

指数损失 [4]：L=e−yzL = e^{-yz}L=e−yz，是 AdaBoost 的损失。它对分错样本的惩罚随错误程度指数增长，比交叉熵更激进，因此对噪声更敏感，但历史上催生了 Boosting 的可学习理论（前向分步加性模型）。

4.4 Focal Loss——重加权交叉熵

类别不平衡场景下，交叉熵被海量易分的负样本主导（∑−log⁡(1−pi)\sum -\log(1-p_i)∑−log(1−pi​) 项堆积）。Focal Loss [8] 在交叉熵上加调制因子：

L=−(1−pt)γlog⁡(pt)L = -(1-p_t)^{\gamma} \log(p_t) L=−(1−pt​)γlog(pt​)

ptp_tpt​ 是模型给真实类别的预测概率，γ>0\gamma > 0γ>0 时易分样本（ptp_tpt​ 大）的损失被 (1−pt)γ(1-p_t)^\gamma(1−pt​)γ 压低，梯度集中在难样本上。γ=0\gamma = 0γ=0 退化为标准交叉熵。它不是新的分布假设，而是对交叉熵的样本重加权——分布假设没变，变的是每个样本在似然中的话语权。

4.5 Weighted LR——按业务价值重加权

Focal Loss 按"难度"重加权，工业界还有按"价值"重加权的经典方案——YouTube 时长建模的 Weighted LR：训练点击概率时，把正样本的损失乘上观看时长 TiT_iTi​：

L=−∑i=1NTi[yiln⁡σ(zi)+(1−yi)ln⁡(1−σ(zi))]\mathcal{L} = -\sum_{i=1}^{N} T_i \big[y_i \ln \sigma(z_i) + (1-y_i)\ln(1-\sigma(z_i))\big] L=−i=1∑N​Ti​[yi​lnσ(zi​)+(1−yi​)ln(1−σ(zi​))]

从似然视角看它的本质：把样本 iii 的似然贡献取 TiT_iTi​ 次幂——

∏i=1N[πiyi(1−πi)1−yi]Ti\prod_{i=1}^{N} \Big[\pi_i^{y_i}(1-\pi_i)^{1-y_i}\Big]^{T_i} i=1∏N​[πiyi​​(1−πi​)1−yi​]Ti​

取对数后，权重自然落到每一项上。伯努利分布假设没有变，变的是每个样本在似然中的话语权：一个看了 40 分钟的正样本，比一个看了 10 秒的正样本"大声" 240 倍。训练收敛后，ew⋅xe^{w \cdot x}ew⋅x 不再是点击概率，而直接成为期望观看时长的估计（校准性质的理论与实验详见上一篇博客《推荐系统时长建模的 Weighted LR 调查》）。

代价是概率语义被破坏：输出不再是校准的点击率，需要时还得后处理还原。这个缺陷恰好引出与 3.7 节的呼应：当"加权"不足以表达数据机制时，就该换分布假设了。WLR 与 ZILN 因此构成时长建模的两条路线：前者用最小改动（加权似然）逼近目标，后者用正确的复合分布一步到位。我的选法很简单——只要相对排序、pCTR 又低，WLR 的最小改动就够用；一旦要校准的绝对值、要分位数输出，就得回到 ZILN 的复合分布。

选型逻辑就一句：先看数据的生成机制像哪种分布，再让损失函数从分布里长出来。数据是计数就用泊松，噪声重尾就用 MAE/Huber，标签是类别就用交叉熵。损失函数从来不是从工具箱里"挑"出来的，是从分布假设里"推"出来的。

六、结语

从 MSE 到 Focal Loss，每个损失函数都是某个分布假设下负对数似然的化身：高斯给出 MSE，拉普拉斯给出 MAE，它们的混合给出 Huber，伯努利给出交叉熵，泊松给出计数损失。连"对异常值敏感"这种工程特性，都能追溯到分布尾部的形状。理解了这条主线，遇到新损失函数时的第一反应不再是"背公式"，而是问一句：它假设了什么分布？把这个问题问出来，损失函数就从一堆需要记忆的公式，变成了一张可以随时推导出来的地图。
